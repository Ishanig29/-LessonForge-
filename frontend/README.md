# LessonForge frontend

React + TypeScript + Vite + Tailwind. See the root README for the full documentation.

```bash
npm install
npm run dev         # http://localhost:5173, proxies /api to http://127.0.0.1:5000
npm test            # Vitest + React Testing Library
npm run typecheck   # tsc -b
npm run build
```
No API keys belong here. All secrets stay in `backend/.env`.
